# Machine Learning Regression

Coursework project applying regression techniques end-to-end on a tabular dataset.

## Pipeline

1. `scripts/01.data_preparation.ipynb` — cleaning, missing values, splits
2. `scripts/02.feature_engineering.ipynb` — transformations and feature selection
3. `scripts/03.Linear_Regression.ipynb` — model fitting and evaluation

## Structure

```
data/
  input/    raw data
  output/   processed data and model outputs
scripts/    notebooks (run in order)
```

## Stack

Python, Jupyter, scikit-learn, pandas.
